# 나만의 프롬프트 관리 프로그램

GenAI 미션을 하며 쌓인 프롬프트를 한곳에서 관리하는 파이썬 콘솔 프로그램입니다.
카테고리별 분류, 키워드 검색, 즐겨찾기를 지원합니다.

## 실행 방법

Python 3.10 이상이 필요하며 외부 라이브러리는 사용하지 않습니다.

```bash
python main.py
```

메뉴 번호를 입력해 기능을 선택하고, `0`을 입력하면 종료됩니다.
데이터는 프로그램 실행 중에만 유지되며 종료하면 기본 데이터로 초기화됩니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 등록 (빈 값은 재입력 요청) |
| 2 | 프롬프트 목록 | 번호, 카테고리, 제목, 즐겨찾기(⭐) 표시 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 프롬프트 검색 (대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 번호로 제목, 카테고리, 즐겨찾기 여부, 내용 전체 출력 |
| 6 | 즐겨찾기 관리 | 번호로 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 출력 |
| 0 | 종료 | 프로그램 종료 |

잘못된 번호를 입력하면 안내 메시지를 출력하고 메뉴를 다시 보여줍니다.

## 카테고리

| 카테고리 | 용도 |
|---|---|
| 텍스트 생성 | 글쓰기, 요약, 번역 등 텍스트 생성용 프롬프트 |
| 이미지 생성 | 이미지 생성 AI용 키워드와 지시문 |
| 영상 생성 | 영상 스크립트, 장면 구성용 프롬프트 |
| 페르소나 | AI의 역할과 말투를 정하는 프롬프트 |
| 자동화 | 노코드 자동화 등 반복 작업에 쓰는 프롬프트 |
| 기타 | 위에 해당하지 않는 프롬프트 |

추가할 때 목록에서 고르거나 새 카테고리 이름을 직접 입력할 수 있습니다.

## 코드 구성

기능별로 함수를 분리했습니다.

- 메뉴: `show_menu()`, `main()`
- 입력 검증: `input_nonempty()`, `input_number()`, `choose_category()`
- 출력: `format_line()`, `print_prompts()`
- 기능: `add_prompt()`, `show_list()`, `show_by_category()`, `search_prompt()`, `show_detail()`, `toggle_favorite()`, `show_favorites()`

## Git 작업 방식
